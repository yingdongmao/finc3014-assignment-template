# AI Co-Pilot Log

We **encourage** you to use AI tools (ChatGPT, Claude, GitHub Copilot, …). We
**require** you to use them critically and document them here. This is a graded
component (D1–D3) and builds the AI literacy that is now a core finance skill.

Rules of thumb:
- Document any AI interaction that **shaped a decision** (a strategy idea, a
  formula, a piece of code, an interpretation).
- For each, record what you asked, what it said, and **your verdict** — was it
  right? Did you change anything? How did you check?
- AI is a co-pilot, not the pilot. Pasting AI output as your own analysis,
  undocumented, is an academic-integrity matter.
